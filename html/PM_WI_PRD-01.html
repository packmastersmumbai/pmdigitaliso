Production Work Instructions - Downfilling

PM/WI/PRD-01|Rev 2.0|06/09/2026|ISO 9001:2015 cl 8.5.1|Retention Controlled copy - display at work station
To define step-by-step work instructions for downfilling operations to ensure accurate fill weights, consistent quality, and safe handling of chemicals and lubricants.
Scope
Applies ToCovers all downfilling (decanting) operations: chemical downfilling from bulk containers to smaller packs, lubricant filling, and solvent dispensing.
ResponsibleProduction Manager oversees operations. Downfilling Machine Operator executes. QC Inspector verifies fill accuracy.
Sequence at a Glance
StepActionCriticalReference
1Verify line clearance and batch production orderCRITICALPM/FRM/PRD-02
2Check raw material identity, batch, and QC release statusCRITICAL
3Set filling machine parameters per product specificationCRITICAL
4Perform first-off weight check and adjust if neededCRITICAL
5Run filling with periodic weight and visual checksPM/FRM/IPQC-01
6Seal containers and apply batch labelsCRITICAL
7Record fill quantities on batch travellerPM/FRM/PRD-01
8Hand over filled goods to QC for final inspection
How to Do It

A step marked CRITICAL must not be skipped or done out of order. If anything is abnormal: STOP the machine, CALL the supervisor, WAIT for instruction.
